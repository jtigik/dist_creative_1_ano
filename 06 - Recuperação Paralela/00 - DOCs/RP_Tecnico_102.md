**Plano de Trabalho para Recuperação de Conceito – 1º Ano do Ensino Médio Profissionalizante – SENAC Distrito Criativo**

---

**Título da Aula**  
Recuperação de Conceitos Fundamentais de HTML e CSS: Desenvolvimento de um Projeto de Site Completo

---

**Objetivo Geral**  
Apoiar o aluno na revisão e consolidação dos fundamentos de HTML e CSS, criando um site completo do zero. A ideia é reforçar o que foi aprendido no 2º trimestre, combinando teoria e prática, para que o aluno ganhe confiança e autonomia na construção de páginas web.

---

**Objetivos Específicos**  
1. Revisar os conceitos teóricos de estruturação de páginas com HTML (tags, elementos, semântica) e estilização com CSS (seletores, propriedades, layout).  
2. Aplicar os conhecimentos revisados na criação de um site funcional com pelo menos três páginas interligadas.  
3. Desenvolver habilidades de resolução de problemas e autonomia na pesquisa de soluções para desafios técnicos.  
4. Garantir a compreensão de boas práticas de organização de código e acessibilidade web.  

---

**Conteúdo Abordado**  
1. **HTML**  
   - Estrutura básica de um documento HTML.  
   - Tags semânticas (header, nav, main, section, footer, etc.).  
   - Criação de links entre páginas.  
   - Uso de formulários e tabelas.  
2. **CSS**  
   - Seletores (ID, classe, elemento) e especificidade.  
   - Propriedades de estilização (cores, fontes, margens, padding).  
   - Modelos de layout (Flexbox e Grid).  
   - Introdução à responsividade (media queries).  
3. **Boas Práticas**  
   - Organização de arquivos e pastas (HTML, CSS, imagens).  
   - Comentários no código.  
   - Noções básicas de acessibilidade (atributos alt, ARIA, contraste).  

---

**Metodologia**  
1. **Aula Introdutória (2 horas)**  
   - Revisão teórica dos conceitos de HTML e CSS abordados no 2º trimestre, com uso de slides e exemplos práticos.  
   - Discussão guiada sobre os erros comuns identificados na avaliação do aluno.  
   - Atividade prática inicial: corrigir um trecho de código com erros fornecidos pelo professor.  

2. **Desenvolvimento do Projeto (6 horas)**  
   - Orientação para criação de um site com tema à escolha do aluno (ex.: portfólio pessoal, página de um evento ou loja virtual).  
   - Divisão do projeto em etapas:  
     - **Etapa 1**: Planejamento do site (wireframe simples e definição de estrutura de páginas).  
     - **Etapa 2**: Criação da estrutura HTML para três páginas interligadas.  
     - **Etapa 3**: Aplicação de estilos CSS, incluindo layout e responsividade básica.  
   - Acompanhamento individualizado para esclarecimento de dúvidas e resolução de problemas.  

3. **Atividade Final (2 horas)**  
   - Apresentação do site desenvolvido pelo aluno.  
   - Feedback do professor com foco em melhorias e reforço de conceitos.  
   - Reflexão escrita do aluno sobre o processo de aprendizagem e desafios superados.  

---

**Recursos Didáticos**  
- Computadores com acesso à internet e editores de código (ex.: Visual Studio Code).  
- Slides ou material digital com resumo de HTML e CSS.  
- Exemplos de códigos comentados.  
- Acesso a plataformas de apoio (W3Schools, MDN Web Docs).  
- Papel e caneta para esboço de wireframes.  
- Projetor para apresentação do conteúdo teórico e demonstrações práticas.  

---

**Avaliação**  
- **Critérios de Avaliação**:  
  1. **Funcionamento do site (40%)**: Estrutura HTML válida, links funcionais e estilização CSS aplicada corretamente.  
  2. **Organização do código (30%)**: Uso de boas práticas (semântica, comentários, organização de arquivos).  
  3. **Autonomia e resolução de problemas (20%)**: Capacidade de buscar soluções para desafios técnicos durante o desenvolvimento.  
  4. **Reflexão escrita (10%)**: Clareza na descrição do processo de aprendizagem e identificação de pontos de melhoria.  
- **Entrega**: O aluno deverá entregar o projeto em formato digital (arquivos HTML, CSS e imagens) e apresentar o site funcional ao professor.  
- **Nota mínima**: 7,0 para aprovação, com base nos critérios acima.  

---

**Observações**  
- O aluno será incentivado a consultar materiais de apoio (como W3Schools e MDN Web Docs) para desenvolver autonomia.  
- Caso o aluno apresente dificuldades específicas, o professor poderá oferecer materiais adicionais ou sessões de reforço individual.  
- O tema do site pode ser escolhido pelo aluno, mas deve ser aprovado pelo professor para garantir adequação ao nível de complexidade esperado.  
- O cronograma pode ser ajustado conforme o progresso do aluno, com possibilidade de mais horas de acompanhamento, se necessário.  

--- 

Esse plano visa atender às necessidades do aluno, promovendo a recuperação dos conceitos do 2º trimestre de forma prática e estruturada, com foco no desenvolvimento de habilidades técnicas e autonomia.
